MEDPASS STATIC CLIENT DEMO
=========================
Open index.html in a modern browser. Internet is required for Bootstrap CDN styling/icons.

Included:
- Responsive homepage and event information
- Student registration form with client-side validation
- Registration review and ₹499 checkout screen
- Simulated payment success
- Digital pass preview and print action
- Login preview and FAQ

IMPORTANT:
- This is a static design/demo only. It does not store registrations on a server.
- Payment button only simulates success; no money is charged.
- The QR area is a decorative placeholder, not a scannable or valid entry QR.
- Do not use for live registrations or actual payments.
- To connect Razorpay test mode safely, use a backend to create orders and verify payment signatures. Never put the Razorpay Key Secret in frontend JavaScript.
- Event dates/location are sample content and should be confirmed by the client.
